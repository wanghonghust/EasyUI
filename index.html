当然可以！以下是一个简洁、实用的 QML（Qt Meta-Object Language）入门示例，展示如何创建一个带按钮和文本的交互式窗口（使用 Qt Quick），适用于 Qt 6 或 Qt 5.15+。

? 示例：Hello World + 点击计数器（完整可运行）

?? main.qml

import QtQuick 2.15
import QtQuick.Controls 2.15
import QtQuick.Layouts 1.15

ApplicationWindow {
    id: window
    visible: true
    width: 400
    height: 300
    title: "QML 示例：计数器"

    ColumnLayout {
        anchors.fill: parent
        anchors.margins: 20
        spacing: 16

        Text {
            text: "点击次数：" + counter.value
            font.pixelSize: 20
            Layout.alignment: Qt.AlignHCenter
        }

        Button {
            text: "点我！"
            Layout.alignment: Qt.AlignHCenter
            onClicked: counter.value++
        }

        // 隐藏的计数器（用 QtObject 封装状态，更清晰）
        QtObject {
            id: counter
            property int value: 0
        }
    }
}

?? 运行方式（任选其一）

? 方法 1：使用 qml 命令行工具（推荐快速验证）

确保已安装 Qt（含 qml 工具，如 Qt 6.5+ 的 Qt Creator 或 qt6-base 包）：

qml main.qml

? 方法 2：C++ 主程序加载（Qt 6 推荐方式）

main.cpp 
#include <QGuiApplication>
#include <QQmlApplicationEngine>

int main(int argc, char *argv[]) {
    QGuiApplication app(argc, argv);
    QQmlApplicationEngine engine;
    const QUrl url(u"qrc:/main.qml"_qs);
    QObject::connect(&engine, &QQmlApplicationEngine::objectCreationFailed,
        &app, []() { QCoreApplication::exit(-1); },
        Qt::QueuedConnection);
    engine.load(url);
    return app.exec();
}
CMakeLists.txt（Qt 6 CMake 方式）
cmake_minimum_required(VERSION 3.16)
project(QmlExample LANGUAGES CXX)

find_package(Qt6 REQUIRED COMPONENTS Core Quick Controls2)

qt_standard_project_setup()

qt_add_executable(QmlExample
    main.cpp
    main.qml
)

qt_add_qml_module(QmlExample
    URI "QmlExample"
    VERSION 1.0
    QML_FILES main.qml
)

target_link_libraries(QmlExample PRIVATE
    Qt6::Core
    Qt6::Quick
    Qt6::QuickControls2
)

?? 提示：.qml 文件需放在 resources 或正确 qrc 路径下；若用文件系统路径，engine.load("main.qml") 即可。

?? 补充说明

概念

说明

ApplicationWindow

Qt Quick Controls 中的顶层窗口（需 import QtQuick.Controls）

ColumnLayout

布局组件，自动垂直排列子项

Button / Text

基础控件，声明式语法，属性绑定（如 text: "次数：" + counter.value）实时响应变化

QtObject

轻量级数据对象，适合封装逻辑状态（比全局 JS 变量更结构化）
